# 复跑说明（REPRODUCE）

本目录是博客《AI 评审测试用例｜清单全绿，为什么我还不敢放行》的全部实验材料。两个实验均可复跑。

## 目录结构

- `实验1-材料与设计.md`：需求原文、12 条带缺陷用例集、组 1/组 2 评审指令全文、7 考点预置答案表与评分规则
- `实验1-结果统计.md`：逐轮评分与局限说明
- `outputs/`：六轮评审原始输出（组1-R1/R2/R3、组2-三轮含 R1、组2-R2/R3）与两份测试员报告
- `实验2-植入缺陷模拟/`：login_sim.py（植入缺陷的模拟程序）、README.md（黑盒说明）、checklist_v1.md（初版清单）、DEFECT.md（缺陷说明，复跑前请勿先读）
- `实验2-结果统计.md`：R1/R2 对照结果

## 复跑实验 1

1. 从 `实验1-材料与设计.md` 取需求与用例集，分别按组 1、组 2 的指令发给任意 AI 模型（模型与参数自定，请在结果中注明）；
2. 每组重复 3 轮（每次新开对话）；
3. 按 7 考点答案表逐项对照打分：命中计 1、部分命中计 0.5、未提计 0；误报=将正确条目报为问题；
4. 与 `实验1-结果统计.md` 对照。注意：换模型/换参数后结果可能不同——这正是「结论限于本条件」的含义。

## 复跑实验 2

1. 进入 `实验2-植入缺陷模拟/`，先只读 README.md 与 checklist_v1.md（不要读 DEFECT.md 和 login_sim.py 源码，读了就失去黑盒意义）；
2. 把「按清单执行+你的边界指令」交给一个 AI 代理（能执行命令行即可），或自己手工执行：`python3 -I login_sim.py reset` 后按 checklist_v1.md 逐条操作（命令模板见 README）；
3. 分别用两种边界指令跑两遍：A. 严格禁止清单外测试；B. 允许清单外补充；
4. 复跑完再读 DEFECT.md 核对：A 是否给出了放行建议，B 是否发现跨会话计数缺陷。

## 已知局限（复跑前必读）

- 评审员/测试员为同一家族 AI 子代理，具体版本对读者不可核查，按未知处理；每条件样本量 1–3 轮；
- 实验 1 的判据文本点名了部分考点，检验的是「给出这套提示后的表现」；
- 复核时间与成本台账均为估计值/假设值，未实测。
